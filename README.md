# ERoomRent Manual Testing Project

## Project Overview

This repository contains a complete Manual Testing project performed on the ERoomRent Web Application.

The project follows the Software Testing Life Cycle (STLC) and includes test planning, test case design, test execution, defect reporting, and project documentation.

---

## Application Under Test

ERoomRent – Online Property Rental Platform

### Modules Tested

* Search Module
* Home Page
* Owner Module
* Broker Module
* Mobile Navigation
* Footer Section
